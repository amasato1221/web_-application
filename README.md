# 成果発表会 資料（従業員情報管理システム empsys）

プロジェクト型演習（JavaWeb）の成果発表会で使う発表資料です。
**記入はすべて GitHub の画面上で行います。** PowerPoint を持っていなくても、ブラウザだけで書き込めます。

```
記入シート.yml を GitHub 上で編集して保存
        ↓（GitHub Actions が自動で実行。2〜3分）
成果発表会資料_テンプレート.pptx が作り直される
```

## 収録ファイル

| ファイル | 内容 | 班員が触るか |
|---|---|---|
| `記入シート.yml` | 発表資料に載せる内容（記入欄） | **ここだけ編集する** |
| `成果発表会資料_テンプレート.pptx` | 記入シートから自動で作られる発表資料（16:9、12〜13枚） | ダウンロードして使う（直接編集しない） |
| `tools/` | 資料を生成するプログラムとテスト | 触らない |
| `.github/workflows/build-slides.yml` | 自動生成の設定 | 触らない |

## 1. 書き込み方（班員向け）

対象ブランチは `claude/quirky-planck-p9p7xg` です。

1. GitHub でこのリポジトリを開き、ブランチを `claude/quirky-planck-p9p7xg` に切り替える
2. `記入シート.yml` を開き、右上の鉛筆アイコン（Edit this file）を押す
3. 自分の担当部分を書き換える（書き方は次の「2. 記入シートの書き方」を参照）
4. 右上の「Commit changes...」を押す
5. メッセージ欄に何を書いたかを入れ（例：`氏名2の感想を記入`）、「Commit directly to the `claude/quirky-planck-p9p7xg` branch」を選んで「Commit changes」を押す
6. 2〜3分待つと、`成果発表会資料_テンプレート.pptx` が自動で作り直される

### 反映されたかの確認

- リポジトリ上部の「Actions」タブを開くと、「発表資料の自動生成」の実行結果が見られます。
  - 緑のチェック：成功。pptx が作り直されています
  - 赤のバツ：失敗。記入シートの書き方に誤りがあります（「4. うまくいかないとき」を参照）
- 成功すると、「発表資料を記入シートから自動生成」というコミットが自動で追加されます。

### 何人かが同時に書くとき

- 保存する直前に、他の人が先に保存していると「ファイルが変更されています」という表示が出ることがあります。そのときは自分の書いた内容をメモ帳などに控え、ページを再読み込みしてから書き直してください。
- 担当を分けて、自分の担当部分だけを書き換えるようにすると衝突しにくくなります。

## 2. 記入シートの書き方

```yaml
メンバー:
  - 氏名: 山田太郎          ← 「: 」の後ろに半角スペースを1つ
    担当作業: ログイン・ログアウト
    良かった点: 【記入】     ← 【記入】のままだとスライドで橙色の記入欄になる
```

| ルール | 説明 |
|---|---|
| 「項目名: 値」 | `:` の後ろに**半角スペース**を必ず入れる |
| 字下げ | 行頭の半角スペースの数を変えない（全角スペース・タブは使わない） |
| 【記入】 | 【記入】で始まる値は、スライド上で**橙色の斜体**（未記入の印）になる。書き換えると自動で通常の文字色になる |
| 「例：」 | 下書きの例文。そのまま使わず、チームの実際の内容に書き換える |
| 文字数 | シート内のメモにある文字数は、スライドの枠に収まる目安 |
| `#` | `#` から行末まではメモ。スライドには出ない |

### 項目とスライドの対応

| 記入シートの項目 | 反映されるスライド | 件数 |
|---|---|---|
| チーム名・発表日 | 表紙、最後のスライド | — |
| メンバー（氏名・担当作業） | 表紙、開発の進め方（役割分担） | 3〜4名（1人目がリーダー） |
| メンバー（良かった点・反省点・次に活かしたいこと） | 個人ごとの感想 | — |
| デモのログインID | デモ：基本ルート | — |
| 開発環境 | 開発環境とプログラム構成 | 1〜6件 |
| 追加課題（実装した・見どころ） | 機能一覧、デモ：追加課題 | — |
| 学んだこと | 学んだこと | 1〜3件 |
| 苦労したこと | 苦労したこと・難しかったこと | 1〜3件 |
| テスト結果・工夫点 | 工夫点 | 工夫点は1〜3件 |
| 企業課題Iへの要望・来年の授業への改善点 | 今後の授業への要望 | 各1〜4件 |

### チームに合わせて自動で変わるところ

| 記入シートの書き方 | スライドの変化 |
|---|---|
| メンバーを3名にする | 個人ごとの感想が3列になる |
| 追加課題の「実装した」を `false` にする | 機能一覧からその機能が消える |
| 追加課題を両方 `false` にする | デモ：追加課題のスライドがなくなる |
| 件数を減らす（学んだこと・苦労したこと等） | 枠の数が減る |

### 下書き済みで確認が必要な内容

- **開発環境：** バージョンが自分たちのPCと同じか
- **苦労したこと：** テスト仕様書の備考から拾った例。チームの実感と違えば書き換える
- **テスト結果：** テスト仕様書の集計欄が項目総数49・実施数50で一致していないため、最終版の数字に直す

## 3. 資料のダウンロードと発表

1. `成果発表会資料_テンプレート.pptx` を開き、右上のダウンロードボタン（下向き矢印のアイコン）を押す
2. PowerPoint で開いて内容を確認する。各スライドのノート欄に、話すポイントと時間の目安があります

> **注意：** ダウンロードした pptx を直接編集しても、次に記入シートが保存されたときに上書きされます。内容の修正は必ず記入シートで行ってください。
> 画面のスクリーンショットなど、記入シートで扱えないものを足したい場合は、全員の記入が終わってから、ダウンロードした pptx に追加してください。

### 時間配分（1チーム 8〜12分、全員がホワイトボード前で発表）

| スライド | 時間の目安 |
|---|---|
| 表紙 | 0.5分 |
| システム概要（4枚） | 1.5分（最初のチームのみ発表。資料は全チーム作成） |
| デモ：基本ルート（ログイン → 登録 → 一覧表示 → 削除 → ログアウト） | 2.5分 |
| デモ：追加課題 | 1.5分 |
| 学んだこと／苦労したこと／工夫点 | 3分 |
| 個人ごとの感想 | 2分（1人30秒） |
| 今後の授業への要望・結び | 1.5分 |

### デモの準備

1. Tomcat と MySQL を起動し、ブラウザで `http://localhost:8080/empsys/` を開く
2. デモで使うログインIDと、登録・削除に使う従業員データ（例：従業員コード 9001）を決めておく
3. 操作する人と説明する人を決め、通しで一度リハーサルする

### 発表前のチェックリスト

- [ ] スライドに橙色の【記入】が残っていない
- [ ] 下書きの内容（開発環境・苦労したこと・テスト結果）を確認した
- [ ] リハーサルで 8〜12分に収まった
- [ ] デモ環境が動くことを当日の朝に確認した

## 4. うまくいかないとき

| 症状 | 対処 |
|---|---|
| Actions が赤のバツになった | 失敗した実行を開き、「記入シートから資料を生成」の行を見る。直す箇所が日本語で表示されるので、記入シートを修正して保存し直す |
| 「○行目付近の書き方が正しくありません」 | その行の `: ` の後ろに半角スペースがあるか、字下げがずれていないかを確認する |
| 「メンバーは3〜4件で書いてください」など | 件数の上限・下限を超えている。項目を増減する |
| 保存したのに pptx が変わらない | Actions タブで実行中か確認する。数分待ってからページを再読み込みする |
| 鉛筆アイコンが押せない | リポジトリへの書き込み権限がない。管理者に共同編集者（Collaborator）への追加を頼む |
| 文字が枠からはみ出している | 文字数を減らす（シート内のメモの文字数が目安） |

## 5. 管理者向けの情報

### 初期設定

- 班員を **Settings → Collaborators** から共同編集者に追加する（書き込み権限が必要）
- **Settings → Actions → General** で、Actions が有効になっていること、「Workflow permissions」が「Read and write permissions」になっていることを確認する

### 生成プログラムを手元で動かす

Node.js 22 以上が必要です。

```bash
cd tools
npm ci          # 依存パッケージのインストール
npm test        # テスト（カバレッジ付き）
npm run build   # 記入シート.yml から pptx を生成
```

- `tools/lib.js`：記入シートの読み込み・検証
- `tools/build.js`：スライドの生成
- `tools/test/`：テスト（命令網羅・分岐網羅とも100%）
