# 成果発表会 資料テンプレート（従業員情報管理システム empsys）

プロジェクト型演習（JavaWeb）の成果発表会で使う発表資料のテンプレートです。
班員はこのテンプレートをダウンロードし、【記入】欄を埋めて発表資料を仕上げてください。

## 収録ファイル

| ファイル | 内容 |
|---|---|
| `成果発表会資料_テンプレート.pptx` | 発表資料のテンプレート（16:9、全14枚） |
| `README.md` | このファイル（使い方の説明） |

## 1. テンプレートの入手方法

### ブラウザでダウンロードする（おすすめ）

1. GitHub でこのリポジトリを開き、ブランチを `claude/quirky-planck-p9p7xg` に切り替える
2. `成果発表会資料_テンプレート.pptx` をクリックする
3. 画面右上のダウンロードボタン（下向き矢印のアイコン）を押して保存する

### git で取得する

```bash
git clone -b claude/quirky-planck-p9p7xg https://github.com/amasato1221/web_-application.git
```

> **注意：** 元のテンプレートは直接上書きせず、`成果発表会資料_F班.pptx` のようにコピーしてから編集してください。

## 2. スライド構成と時間配分

発表時間は 1チーム 8〜12分です。発表は全員がホワイトボード前に出て行います。

| No | スライド | 時間の目安 | 備考 |
|---|---|---|---|
| 1 | 表紙 | 0.5分 | チーム名・メンバー・発表日 |
| 2 | 発表の流れ | 0.5分 | 時間配分と担当者の表 |
| 3〜6 | システム概要（構成図、機能一覧、開発環境、開発の進め方） | 1.5分 | 発表は最初のチームのみ。資料は全チームが作成する |
| 7 | デモ：基本ルート | 2.5分 | ログイン → 登録 → 一覧表示 → 削除 → ログアウト |
| 8 | デモ：追加課題 | 1.5分 | 従業員情報更新・ユーザ情報登録 |
| 9 | 学んだこと | 1分 | |
| 10 | 苦労したこと・難しかったこと | 1分 | |
| 11 | 工夫点（アピールしたい点） | 1分 | |
| 12 | 個人ごとの感想 | 2分 | 1人30秒程度 |
| 13 | 今後の授業への要望 | 1分 | 企業課題I向け／来年の3年生向け |
| 14 | ご清聴ありがとうございました | 0.5分 | |

合計は約11.5分です。システム概要を発表しないチームは約10分になります。

## 3. 編集のしかた

### 【記入】欄を書き換える

- **橙色の斜体文字**（【記入】で始まる文字）が記入欄です。すべて自分たちの内容に書き換えてください。
- 書き換えた文字は、ホームタブのフォントの色を通常の色（濃い灰色）に、斜体を解除して戻してください。
- 「例：」と書かれている文は記入の参考です。そのまま使わず、チームの実際の内容にしてください。

### 担当者タグを埋める

各スライド右上の「担当：【記入】」「操作：【記入】」のタグに、そのスライドを話す人（デモでは操作する人）の名前を入れてください。

### 話者メモ（ノート）を確認する

各スライドのノート欄に、担当・時間の目安・説明のポイントを書いてあります。
PowerPoint の「表示」→「ノート」で表示できます。発表者ツールを使うと、発表中も手元で確認できます。

### チームに合わせてスライドを調整する

| 状況 | 対応 |
|---|---|
| 3人チーム | スライド12（個人ごとの感想）の4枠目を削除し、残りの枠を広げる |
| 追加課題を実装していない | スライド4の該当行と、スライド8の該当カードを削除する。両方とも未実装ならスライド8ごと削除する |
| 独自の追加機能がある | スライド4に行を追加し、スライド8で紹介する |
| 2チーム目以降の発表 | システム概要（3〜6）は資料に残したまま、発表では省略する |

### 下書き済みの内容を確認する

配布資料（要件定義書・設計書・テスト仕様書・WBS）から分かる内容は下書きしてあります。
実際の内容と違う場合は修正してください。特に次の点は必ず確認してください。

- **スライド5の開発環境：** バージョン（Java 25、Tomcat 11、MySQL 8.4 など）が自分のPCと同じか
- **スライド6の役割分担：** 仮の割り当てなので、実際の分担に書き換える
- **スライド10の苦労したこと：** テスト仕様書の備考から拾った例。チームの実感と違えば差し替える
- **スライド11のテスト件数：** テスト仕様書の集計欄は項目総数49・実施数50で一致していないため、最終版の数字に直す

## 4. デモの準備

1. Tomcat と MySQL を起動する
2. ブラウザで `http://localhost:8080/empsys/` を開き、ログイン画面が出ることを確認する
3. デモで使うログインIDと、登録・削除に使う従業員データ（例：従業員コード 9001）を決めておく
4. 操作する人と説明する人を決め、通しで一度リハーサルする

- 登録した従業員をデモ中にそのまま削除すると、デモ後にデータが元に戻ります。
- 万一動かなかったときのために、各画面のスクリーンショットを予備スライドとして用意しておくと安心です。
